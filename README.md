# Student Management System - Java | JDBC | MySQL

A Java-based CRUD application to manage student records using JDBC and MySQL.

## 🚀 Features
- Add new student
- View all students
- Search student by ID
- Update student details
- Delete student

## 🛠️ Tech Stack
- Java (Core Java, OOP, Collections)
- JDBC with PreparedStatement
- MySQL Database
- Eclipse IDE / VS Code
- Git & GitHub

## 📂 Project Structure
StudentManagement/
├── Student.java
├── StudentDAO.java
└── Main.java

## ⚙️ How to Run
1. Create MySQL DB: `student_db`
2. Create table `students` (id, name, email, course)
3. Add MySQL Connector JAR to Eclipse
4. Update DB username/password in StudentDAO.java
5. Run Main.java
